CoverageMap (AFL-style Bitmap)

CoverageMap(
  bitmap: bytearray[65536],  # 64KB bitmap — 에지 하나당 1바이트
  edge_count: int,            # 0이 아닌 엔트리 수
)

# 에지 인덱스 = (source_block XOR dest_block) % 65536
# 각 바이트는 해당 에지의 hit count

Hit-Count Bucketing (AFL 표준)

실행 횟수를 버킷으로 압축하여 "1번 vs 2번"같은 노이즈를 제거한다:

bucket(count) = min{ x ∈ [1, 2, 3, 4, 8, 16, 32, 128] : count ≤ x }

예: hit count 5 → bucket 8, hit count 17 → bucket 32

Novelty Check Algorithm

def has_new_bits(existing, new) → bool:
    for i in range(65536):
        if new.bitmap[i] > 0 and existing.bitmap[i] == 0:
            return True   # 완전히 새로운 에지
        if bucket(new[i]) != bucket(existing[i]):
            return True   # 새로운 hit-count 버킷
    return False

3. Fuzzing Engine — Main Loop

Phase 1: Seeding

  1. seeds_dir에서 파일 기반 시드 로드 (있으면)
  2. Grammar으로 초기 시드 생성 (기본 100개)
  3. 각 시드를 primary + reference 타겟에 실행
  4. 커버리지 수집 & 오라클 체크 → 코퍼스에 추가

Phase 2: Main Loop

while running and not should_stop():

    # 1. 시드 선택 (에너지 가중 확률)
    seed = seed_scheduler.select(corpus)
    seed.exec_count += 1

    # 2. 뮤테이터 선택
    mutator = mutator_scheduler.select(mutators, seed)

    # 3. 변이 생성
    mutated = mutator.mutate(seed.input, corpus.seeds)

    # 4. 실행 (primary + references 병렬)
    result = target.execute(mutated)
    ref_results = ThreadPool.map(ref.execute, mutated)

    # 5. 커버리지 신규성 판단
    new_cov = coverage.collect(result, ref_results)
    is_novel = coverage.is_novel(corpus.global_coverage, new_cov)
    if is_novel:
        corpus.add(mutated, new_cov, parent_id=seed.id)

    # 6. 모든 오라클로 버그 탐지
    for oracle in oracles:
        findings = oracle.check_with_refs(mutated, result, ref_results)
        for f in findings:
            if not dedup.is_duplicate(f):
                dedup.register(f)
                stats.record_finding(f)

    # 7. 스케줄러 피드백
    result_info = ScheduleResult(
        found_new_coverage=is_novel,
        found_crash=has_crash,
        new_edges=new_seed.feature_set
    )
    seed_scheduler.update(seed, result_info)
    mutator_scheduler.update(mutator, result_info)
Stopping 조건: max_iterations 도달, max_time_secs 초과, 또는 외부 SIGTERM/stdin 명령

Expansion Algorithm

def _expand_rule(grammar, rule_name, depth, max_depth):
    rule = grammar.rules[rule_name]

    # 깊이 제한: 무한 재귀 방지
    if depth >= max_depth:
        # 터미널 프로덕션만 선택 (rule_ref 없는 것)
        candidates = rule.terminal_productions()
        if not candidates:
            candidates = [minimal_production(rule)]  # 최소 재귀
    else:
        candidates = rule.productions

    # 가중치 기반 확률 선택
    production = random.choices(
        candidates,
        weights=[p.weight for p in candidates]
    )[0]

    # 각 심볼 재귀 확장
    return "".join(
        _expand_symbol(s, depth + 1, max_depth)
        for s in production.symbols
    )

# Hard ceiling: depth ≥ 2 × max_depth → 강제 터미널

6. Seed Scheduling Algorithms

어떤 시드를 다음에 변이할지 결정하는 알고리즘. 모든 스케줄러는 select(corpus)와 update(seed, result)를 구현한다.

6.1 EntropicScheduler 기본값

LibFuzzer (FSE'20)에서 제안된 정보 이론 기반 에너지 할당.

핵심 아이디어: "희귀한 feature를 발견한 시드에 더 많은 에너지를 준다." 희귀할수록 정보량(information)이 높다.

Information Content

I(f) = −log2( freq(f) / total_seeds )

freq(f): feature f를 가진 시드 수. total_seeds: 전체 코퍼스 크기.

예: feature가 320개 시드 중 2개만 가지고 있으면 → I = −log2(2/320) = 7.32 bits

Seed Entropy (Energy)

entropy(seed) = ∑f ∈ seed.feature_set, freq(f) < θ I(f)
seed.energy = entropy × base_energy

Abundance threshold (θ = 256): feature가 256개 이상의 시드에서 발견되면 "abundant"로 간주, 엔트로피 계산에서 제외.

Selection

# 에너지 × 외부 부스트 비례 확률 선택
weights = [max(seed.energy * seed.priority_boost, 0.01) for seed in corpus]
selected = random.choices(corpus.seeds, weights=weights)[0]

Update (실행 후)

if found_new_coverage:
    seed.energy *= 1.5    # 보상: 에너지 50% 증가
else:
    seed.energy *= 0.99   # 감쇠: 에너지 1% 감소
Native acceleration: Rust 구현으로 전체 코퍼스 에너지를 벌크 계산. O(seeds × features) → 수천 시드에서도 <1ms.

6.2 EcoFuzzScheduler MAB

EcoFuzz (USENIX Security'20): Multi-Armed Bandit (UCB1) 접근법.

핵심 아이디어: 각 시드를 slot machine의 arm으로 취급. "많이 시도해서 성공률이 높은 시드" vs "아직 안 해본 시드" 사이의 최적 균형을 찾는다.

UCB1 Formula

reward(seed) = successes / trials

UCB1(seed) = reward + C × √( ln(total_trials) / trials )

score(seed) = UCB1 × priority_boost

successes: 새 커버리지 또는 크래시 발견 횟수. trials: 변이 시도 횟수. C: exploration weight.

Selection

# trials=0인 시드는 무한대 우선순위 (즉시 탐색)
selected = max(corpus.seeds, key=lambda s: ucb1_score(s))

AAPS: Adaptive Average-cost Power Schedule

seed.energy = 1.0 + reward_rate × 10.0

보상 비율이 높은 시드에 에너지를 집중.

Exploration vs Exploitation

Exploration

√(ln(N)/ni) 항이 커짐 → 시도 횟수가 적은 시드 선호

Exploitation

reward 항이 커짐 → 성공률이 높은 시드 선호

6.3 RareBranchScheduler FairFuzz

FairFuzz (ASE'18) 영감: 드물게 실행되는 에지를 커버하는 시드에 집중.

rare_score(seed) = | seed.rare_branches | × rarity_weight

rare_branches: 전체 코퍼스에서 소수의 시드만 커버하는 에지 집합. 이런 에지를 가진 시드가 우선 선택되어 under-explored 코드 영역을 탐색한다.

6.4 RandomSeedScheduler Baseline

균일 랜덤 선택. 알고리즘 비교의 baseline.

P(seedi) = 1 / |corpus|

7. Coverage Models

커버리지 정보는 퍼징의 피드백 신호. "이 입력이 새로운 행동을 유발했는가?"를 판단한다.

7.1 EdgeCoverageCollector AFL-style

계측(instrumented) 바이너리에서 실행 경로의 에지(branch transition)를 추적.

edge_index = (source_block XOR dest_block) mod 65536
bitmap[edge_index] += 1 (매 실행 시 hit count 증가)

64KB bitmap으로 65,536개 에지 슬롯. 충돌(collision)이 있지만 실용적으로 충분.

7.2 ResponseCoverageCollector Blackbox

계측 없는 타겟을 위한 응답 기반 유사 커버리지. 6가지 특성 조합으로 "커버리지"를 시뮬레이션.

#FeatureBucketing
1HTTP status code그대로 사용
2Content length[0, 64, 256, 1K, 4K, 16K, 64K, ∞]
3Error signatureSHA256(stderr[:64])
4Response time[10, 50, 100, 250, 500, 1000, 5000, ∞] ms
5Combined{status}:{length}:{time}
6Content-Type헤더 값

각 고유 조합이 bitmap의 한 feature로 매핑된다.

7.3 DiffCoverageCollector Nezha-style

Nezha (IEEE S&P'17) 영감: 타겟 간 행동 차이(divergence)를 커버리지로 취급.

핵심 아이디어: "파서 A는 accept하고 B는 reject한다"는 것 자체가 하나의 "에지"다. 새로운 divergence 패턴을 발견하면 코퍼스에 추가. 
def collect_diff(inp, primary, ref_results):
    bitmap = bytearray(65536)

    # Feature 1: Exit code class 벡터
    classes = [primary.exit_code // 100]
    classes += [r.exit_code // 100 for r in ref_results]
    set_feature(bitmap, "exit_classes", str(classes))

    # Feature 2: 쌍별 divergence
    for i, ref in enumerate(ref_results):
        divs = set()
        if primary.exit_code != ref.exit_code:
            divs.add("exit")
        if primary.stdout != ref.stdout:
            divs.add("output")
        if primary.duration_ms > ref.duration_ms * 10:
            divs.add("timing")
        set_feature(bitmap, f"div_ref{i}", str(sorted(divs)))

    # Feature 3-5: Status codes, error patterns, divergence count
    ...

    return CoverageMap(bitmap)

새로운 divergence 패턴이 발견되면 코퍼스에 추가 → 스케줄러가 이런 시드에 에너지를 집중 → 더 많은 차이 발견.

8.2 DiffOracle (Differential)

Strategy Pipeline

def _collect_all(inp, result, ref_results):
    best_per_strategy: dict[str, Finding] = {}

    for i, ref_result in enumerate(ref_results):
        for strategy in strategies:
            finding = strategy.compare(inp, result, ref_result, i)
            if finding:
                key = strategy.name
                # 같은 전략 중 가장 높은 severity만 유지
                if key not in best or sev_rank(finding) > sev_rank(best[key]):
                    best[key] = finding

    return sorted(best.values(), key=sev_rank, reverse=True)

8.3 SsrfOracle (SSRF Detection)

URL 파서 간 차이에서 SSRF 공격 가능성을 탐지. DiffStrategy로 동작.

핵심 로직: Host Confusion Detection

# 양쪽 파서 출력에서 host 추출

ref_host     = parse_json(ref.stdout)["host"]

# 한쪽은 내부 IP, 다른 쪽은 외부 → SSRF!
if is_internal(primary_host) != is_internal(ref_host):
    return Finding(severity=CRITICAL, category="ssrf_host_confusion")

Internal Host Recognition

def _is_internal_host(host: str) → bool:
    # 1. 직접 매칭: localhost, *.internal, *.local
    if host in _INTERNAL_HOSTNAMES: return True

    # 2. 대체 localhost: 0x7f000001, 017700000001, 2130706433, 127.1
    if host in _LOCALHOST_ALTERNATES: return True

    # 3. 클라우드 메타데이터: 169.254.169.254, 100.100.100.200
    if host in _CLOUD_METADATA_IPS: return True

    # 4. IP 주소 파싱 → RFC 1918 체크
    try:
        addr = ipaddress.ip_address(host)
        return addr.is_loopback or addr.is_private or addr.is_reserved
    except ValueError: pass

    # 5. Hex IP 디코딩: 0x7f000001 → 127.0.0.1
    if host.startswith("0x"):
        decimal = int(host, 16)
        return ipaddress.ip_address(decimal).is_loopback

    return False

9. Deduplication

Fingerprinting Algorithm

def fingerprint(finding: Finding) → str:
    h = hashlib.sha256()

    # 항상 포함
    h.update(finding.oracle_name)           # "differential", "crash", "ssrf"
    h.update(str(finding.severity))         # "HIGH", "CRITICAL"
    h.update(str(finding.result.exit_code)) # 0, 1, -11
    h.update(finding.result.stderr[:256])  # 에러 시그니처

    # Metadata 필드 (있으면 포함)
    h.update(metadata.get("strategy", ""))      # exit_code, output, ssrf...
    h.update(metadata.get("category", ""))      # host_confusion, scheme_mismatch...
    h.update(str(metadata.get("ref_index", ""))) # 어느 reference 타겟
    h.update(",".join(sorted(
        metadata.get("diff_fields", [])         # ["host","scheme"] 등
    )))

    return h.hexdigest()[:16]  # 16자 hex
효과: 같은 구조적 divergence(예: "ref[0]에서 host mismatch")는 dedup되지만, 다른 카테고리(host vs scheme)는 별개 finding으로 유지.
