🚨 1. SSRF Host Confusion CRITICAL 35 findings ▶

Parser A sees an external host, Parser B resolves to an internal IP. Direct SSRF bypass.

1.1 Percent-Encoded Localhost
http://%6c%6f%63%61%6c%68%6f%73%74/admin
ParserHost
urllib%6c%6f%63%61%6c%68%6f%73%74 (encoded, opaque)
WHATWGlocalhost (decoded → internal IP)
Attack Scenario
urllib validates SSRF blocklist → passes (doesn't match "localhost"). WHATWG/browser fetches → resolves to 127.0.0.1.
1.2 Hex IP with Percent-Encoded Dots

Attack Scenario
Double bypass: encoding + hex IP. Extremely hard for WAF detection.
