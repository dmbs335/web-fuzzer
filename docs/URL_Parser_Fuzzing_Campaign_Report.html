Real-World Attack Scenarios for Newly Discovered Components

Port Confusion (34 findings)
http://api.internal:8080/admin
  urllib:  port="8080"
  WHATWG:  port="" (default)

Impact: Kubernetes 내부 서비스 포트 접근. 관리 콘솔(8080, 9090) 우회. Port-based ACL bypass.

Query Confusion (27 findings)
http://app.com/cb?redirect=http://evil.com
  urllib:  query="redirect=http://evil.com"
  rfc3986: query="redirect=http%3A//evil.com"

Impact: OAuth callback 검증 우회. CSRF 토큰 유출. Open redirect via query parameter.

Fragment Confusion (36 findings)
http://app.com/#<script>alert(1)</script>
  urllib:  fragment="<script>alert(1)..."
  WHATWG:  fragment="%3Cscript%3E..."

Impact: SPA hash routing XSS. Fragment를 서버에서 처리하는 애플리케이션 대상.

Path Confusion (45 findings)
http://host/..\..\admin
  urllib:  path="/..\\..\\admin"
  WHATWG:  path="/admin" (normalized)

Impact: Reverse proxy + backend 조합에서 path-based ACL 우회. nginx/Apache + Node.js.
